# 💱 환율 예측 모델 (USD/KRW Forecast Dashboard)

KOSPI · VIX 등 거시지표를 결합한 **앙상블(XGBoost + ARIMA + Prophet)** 퀀트 파이프라인과,
그 결과를 웹에서 확인할 수 있는 **Streamlit 대시보드**입니다.

> ⚠️ **면책 안내**: 본 프로젝트는 학습·참고 목적의 예측 도구입니다. 실제 외환 거래의
> 투자 판단 및 그 결과에 대한 책임은 이용자 본인에게 있습니다.

---

## 📂 구성

| 파일 | 설명 |
|------|------|
| `forecast_core.py` | 예측 엔진. `run_forecast()` 함수가 데이터 수집 → 모델 학습 → 예측 → 시그널 산출까지 수행하고 결과를 dict로 반환합니다. |
| `app.py` | Streamlit 대시보드. 요약 카드 · 대화형 그래프 · 예측표 · 성능 지표 · 설정 사이드바를 제공합니다. |
| `exchange_forecast_v8.py` | 콘솔용 원본 파이프라인 스크립트 (Colab 실행용). |
| `requirements.txt` | 의존성 목록. |

---

## 🚀 실행 방법

### 1) 대시보드 (권장)

```bash
# 1. 의존성 설치
pip install -r requirements.txt

# 2. 대시보드 실행
streamlit run app.py
```

실행하면 브라우저가 열리고, 왼쪽 사이드바에서 **기준일 · 예측 기간**을 설정한 뒤
**[🚀 예측 실행]** 버튼을 누르면 결과가 표시됩니다.

### 2) 콘솔 스크립트 (Colab 등)

```bash
python exchange_forecast_v8.py
```

## 🧠 모델 개요

- **입력 지표**: USD/KRW 종가·고저, DXY(달러인덱스), 미국 10년물 금리, VIX, KOSPI
- **파생 피처**: 이동평균(MA3~60), RSI, MACD, 모멘텀, 거시지표 Lag, 달력 효과(요일·월말·분기말)
- **앙상블**: 세 모델의 OOT 성능을 역수 가중해 결합 (Prophet 가중치 상한 5%)
- **시그널**: 최근 20일 실제 종가의 볼린저 밴드(±1σ) 기준으로 `BUY / HOLD / WAIT` 판정
- **실시간 보정**: 네이버 금융 JSON API로 현재가를 받아 예측을 소폭 재보정 (Re-anchoring)

## 📊 성능 지표 읽는 법

| 지표 | 의미 |
|------|------|
| **MAE / RMSE** | 예측이 실제와 평균 몇 원 차이났는지 (낮을수록 좋음) |
| **예측 정확도 (100 − MAPE)** | 값 오차율 기반. 환율은 하루 변동이 작아 대개 높게 나옴 (착시 주의) |
| **방향성 정확도** | 오를지/내릴지 방향 적중률. **50%면 동전던지기, 55%↑면 유의미** — 실전 핵심 지표 |

> 💡 정확도(%)가 높아도 **방향성 정확도**가 50% 부근이면, 방향 예측은 신뢰하지 않는 것이 좋습니다.
